# Трекер задач

Приложение «Трекер задач» — простой веб-сервис для просмотра и добавления задач. Написан на Go с использованием только стандартной библиотеки (без внешних зависимостей). Шаблоны страницы встраиваются в бинарник через пакет `embed`, данные задач хранятся в JSON-файле.

## Возможности

- Список задач: название, статус, дата создания.
- Добавление задачи через форму (POST /add), с редиректом на главную страницу.
- Проверка живости: GET /healthz возвращает `ok`.
- Плавное завершение работы по сигналу SIGINT/SIGTERM.
- Потокобезопасное хранилище с блокировкой `sync.Mutex` и автоматическим сохранением в `tasks.json`.

## Требования

- Go 1.22 и выше.

## Локальный запуск

```bash
go run .
```

После запуска откройте в браузере `http://localhost:8080`.

## Сборка

```bash
go build -o app .
./app
```

## Переменные окружения

| Переменная     | По умолчанию | Описание                                        |
|----------------|--------------|--------------------------------------------------|
| `PORT`         | `8080`       | Порт, на котором слушает сервер.                |
| `TASKS_FILE`   | `tasks.json` | Путь к файлу с задачами (относительно CWD).      |

## Структура проекта

- `main.go` — точка входа, запуск сервера, graceful shutdown.
- `store.go` — хранилище задач (`TaskStore`), работа с `tasks.json`.
- `handlers.go` — HTTP-обработчики, рендеринг шаблона через `embed`.
- `templates/index.html` — шаблон главной страницы.
- `go.mod` — модуль `tasktracker`.

## Публикация на Render

Создайте `render.yaml` (или используйте веб-интерфейс Render) с конфигурацией:

```yaml
services:
  - type: web
    name: tasktracker
    env: go
    buildCommand: go build -o app .
    startCommand: ./app
    envVars:
      - key: PORT
        value: 8080
```

Render автоматически выставит переменную `PORT`, поэтому приложение будет слушать на нужном порту.
